# OpenArtifact

OpenArtifact is an enterprise-grade, free-as-in-freedom artifact repository manager. It is written in Go with an embedded Vue 3 web UI and uses PostgreSQL for metadata.

It supports Maven, npm, PyPI, Docker/OCI, Helm, Debian, RPM, Go modules, Cargo, NuGet, RubyGems, Conda, Conan, Ivy, sbt and raw repositories, with proxy and group repositories, RBAC, OIDC/SAML SSO, SBOM, vulnerability/license/secret scanning, AI analysis, an MCP server, webhooks and release bundles.

## Where things live

- **Canonical repository:** https://codeberg.org/openartifact/openartifact. Development, issues and pull requests happen here.
- **GitHub mirror:** https://github.com/openartifact/openartifact. A read-only push mirror used for CI.
